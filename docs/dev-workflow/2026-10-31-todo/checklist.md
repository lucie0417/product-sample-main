# 待辦清單測試 Checklist

## 需求與驗收條件

## 測試環境
- 網址：專案根目錄 index.html（file://）
- 啟動方式：直接以瀏覽器開啟
- 前置條件：使用測試清單資料
- 瀏覽器／視窗：尚未啟動；目前未提供 Playwright MCP 與 Chrome DevTools MCP 工具
- 既有程式檢查：上一輪 JavaScript 語法與模擬 DOM 操作檢查通過；不能取代瀏覽器驗證。
